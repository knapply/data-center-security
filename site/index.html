      About

      This tracker covers security events that affect data centers: physical threats (fire, power, cooling, sabotage, cable cuts), IT/OT/SCADA vulnerabilities in facility and server infrastructure, and supply-chain risk for the components data centers depend on.

      Every entry is curated: drafted from public sources, checked against an editorial rubric, and reviewed before publishing. Locations are shown at city or region level only. Where no source names the maker of a failed part, any best guess is labeled as one, with its evidence.

      Data and methodology live in the GitHub repository.
